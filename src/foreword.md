# 前言

## 本书要解决什么问题

数据规模在增长，但单机算力也在增长。当你面对 GB 级甚至 TB 级数据、又不想引入分布式系统的运维复杂度时，Polars 是当前最优解之一。

本书不是 API 文档的搬运，而是围绕一条主线展开：**为什么 Polars 快**。理解了表达式引擎、列式内存、惰性执行与多线程模型的设计，你就能预判每一段代码的性能表现，而不是碰运气式地调优。

两条贯穿全书的工作流主线：

1. **流式操作**：`scan_* → 惰性变换 → sink_*` 的端到端流式管道，内存受控处理超大数据集
2. **链式调用**：以表达式方法链为核心的声明式编程风格，一次构建、整体优化

## 本书为谁而写

- 有 pandas 经验、被性能瓶颈困扰、想系统迁移到 Polars 的数据工程师
- 关注内存布局、并行模型、执行引擎机制的高性能计算工程师

书中代码以 **Python** 生态为主，涉及表达式 plugin 时会展示必要的 Rust 代码。

## 如何阅读

- 第一部分建立心智模型，第二部分下探引擎机制——这是全书的根基
- 每章开头说明"本章要解决什么问题"，结尾附"要点回顾 + 性能检查清单"
- 所有性能论断均注明 Polars 版本与数据规模，避免过时误导

## 环境约定

```text
Python 3.11+，Polars 1.x
```

## 配套代码

本书配套可运行的示例与测试（仓库 `examples/` 与 `tests/` 目录）：

```bash
# 安装依赖并运行测试（校验书中关键代码模式）
uv sync
uv run pytest

# 运行示例脚本
uv run python examples/01_basics.py          # 第 1、2 章：对象与内存模型
uv run python examples/02_lazy_streaming.py  # 第 3、5、6、8 章：惰性与流式
uv run python examples/03_analysis.py        # 第 10、11 章：聚合与时序
uv run python examples/04_extras.py          # 高频补充 API：hist/rle_id/interpolate/lazy sink
```

每章末尾附有练习题，动手完成它们是掌握 Polars 的最短路径。
